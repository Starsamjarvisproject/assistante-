# Compétence : fiches prospects (dormante)

- Niveau opérationnel : 0 % (pas de pont avec le CRM)

## Outils de l'ancien système
- `chercher_fiche(recherche)` : cherche des fiches par nom d'entreprise.
- `lire_fiche(id)` : lit les informations principales d'une fiche (nom, ville, code postal, décideur, téléphone, e-mail, date et heure de RDV).
- `preparer_suppression_fiche(id_fiche)` : suppression définitive d'une fiche entière, sur ordre explicite de Sami uniquement, jamais de ma propre initiative.

## Procédure
Pour toute question sur une entreprise : chercher la fiche, ne jamais inventer. Plusieurs résultats : demander lequel. Si une fiche existe déjà, le dire plutôt que d'en créer une autre.
